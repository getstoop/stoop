# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short form: be kind, assume good faith, argue about the code and not
the person, and take no for an answer. Harassment, personal attacks,
publishing others' private information, and sustained disruption are not
welcome anywhere in the project: issues, pull requests, discussions,
and any chat that speaks for the project.

To report a problem, use GitHub's **Report content** on the offending
item, or contact the maintainer privately through the repository's
Security tab (Report a vulnerability reaches only the maintainer and is
fine to use for conduct reports too). Reports are handled by the
maintainer, and kept confidential. Consequences
range from a request to change behaviour, through a temporary block, to
a permanent ban, at the maintainer's judgement.

The full text of the Covenant, including the enforcement guidelines this
project uses, is at the link above.
